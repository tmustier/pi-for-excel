# v0.12.0-pre release notes

Pre-release. Changes since [v0.11.0-pre](https://github.com/tmustier/pi-for-excel/releases/tag/v0.11.0-pre).

## Undo and backups

- **Undo this turn.** When a turn changes the workbook, one line under it says what changed, with Review and "Undo this turn". Undo reverses the turn's changes newest first and leaves an ordinary backup, so it can itself be undone. It refuses to overwrite cells you edited afterwards unless you say so. Changes made by Pi's own Office.js code have no backup, so the line says they aren't covered and points to `/backup`. [#808](https://github.com/tmustier/pi-for-excel/pull/808)
- **Backups are smaller and faster.** Each backup is stored compressed, with an index, in a 512 MiB budget shared by all workbooks. When the budget is full the oldest backups go first, and a backup too large for the budget is refused rather than evicting everything. The Backups list loads 50 at a time. Backups follow the workbook through Save As, rename and move. [#809](https://github.com/tmustier/pi-for-excel/pull/809), [#794](https://github.com/tmustier/pi-for-excel/pull/794)
- In Confirm mode you can allow the rest of a turn's workbook changes at once. Large deletes ask first in every mode. [#808](https://github.com/tmustier/pi-for-excel/pull/808), [#794](https://github.com/tmustier/pi-for-excel/pull/794)

## Turns, the composer and tabs

- Send sits next to Stop, so there is one visible way to talk to Pi while it works. The working line says what Pi is doing, including "Stopping…". A failed or stopped turn offers Retry, and Up in an empty composer recalls your last message. Provider errors and rate limits explain what happened and when Pi will retry. [#803](https://github.com/tmustier/pi-for-excel/pull/803), [#789](https://github.com/tmustier/pi-for-excel/pull/789)
- Tabs are titled by their conversation instead of "Chat N". Resuming a session always opens or focuses its own tab. Changing the model while Pi is busy applies from the next turn. The command menu is shorter, and commands are refused while busy only when they would conflict. [#805](https://github.com/tmustier/pi-for-excel/pull/805), [#795](https://github.com/tmustier/pi-for-excel/pull/795)
- **New shortcuts (taskpane focused):** Ctrl+Alt+N new tab, Ctrl+Alt+W close tab, Ctrl+Alt+Shift+T reopen a closed tab, Ctrl+Alt+← / → switch tabs, Ctrl+Alt+T cycle thinking. **Changed:** Shift+Tab moves focus backwards again instead of changing thinking, and Ctrl/Cmd+Z no longer reopens tabs. On keyboard layouts where Ctrl+Alt is AltGr (for example Polish or German), Windows types the AltGr character and the Pi shortcut does not fire. [#802](https://github.com/tmustier/pi-for-excel/pull/802)
- Copy table puts a real table on the clipboard, so it pastes into cells. You can insert a cell reference by pointing at the grid. Dark mode now covers the whole pane, including the gear, file buttons and Settings menus. [#802](https://github.com/tmustier/pi-for-excel/pull/802)
- A streaming turn renders once, details mode shows real detail, thinking shows its duration, and each tool card shows when it finished. Overlays, notifications and menus follow one model, with consistent focus and Escape. [#786](https://github.com/tmustier/pi-for-excel/pull/786), [#793](https://github.com/tmustier/pi-for-excel/pull/793)

## Setup and providers

- Provider rows say what each option is, including the local helper. Codex's built-in web search works without a third-party key. Draft attachments can be removed. With an Anthropic subscription login, Pi warns once per session that third-party usage is billed per token, with a setting to turn the warning off. [#811](https://github.com/tmustier/pi-for-excel/pull/811)
- GitHub Copilot login works in the taskpane. Use proxy `0.2.7-pre` or later. [#799](https://github.com/tmustier/pi-for-excel/pull/799)
- Custom gateways can set a maximum output token limit, and local OpenAI-compatible gateways work without the proxy. [#773](https://github.com/tmustier/pi-for-excel/pull/773), [#776](https://github.com/tmustier/pi-for-excel/pull/776)

## Consent and guidance

- Changes to rules, conventions and skills show the new text in Confirm mode and can be undone from a toast. Workbook rules always ask before Pi changes them. [#804](https://github.com/tmustier/pi-for-excel/pull/804)
- MCP tool calls show the server, tool and inputs. In Auto mode you can allow once or always allow a tool, and revoke remembered tools under Connections. Confirm mode asks for every call. [#804](https://github.com/tmustier/pi-for-excel/pull/804)
- Pi asks before overwriting or deleting a Files item it did not create in this chat. Extensions ask before running new code, and in Confirm mode before every change, including reload. [#804](https://github.com/tmustier/pi-for-excel/pull/804), [#790](https://github.com/tmustier/pi-for-excel/pull/790), [#826](https://github.com/tmustier/pi-for-excel/pull/826)

## Reliability

- Read tools handle large and realistic workbooks. Write results report what is actually in the workbook afterwards. Python tools report real errors, never silently re-run, and verify the values they write. [#787](https://github.com/tmustier/pi-for-excel/pull/787), [#791](https://github.com/tmustier/pi-for-excel/pull/791), [#797](https://github.com/tmustier/pi-for-excel/pull/797)
- Auto-context, Excel timeouts and edit attribution are fixed. Compaction summarizes answered requests as done and shrinks large kept results. [#792](https://github.com/tmustier/pi-for-excel/pull/792), [#798](https://github.com/tmustier/pi-for-excel/pull/798)
- Excel on the web: `fill_formula` fills every target cell, copy and export fall back when the clipboard is blocked, the language switch applies, and startup and storage issues are fixed. [#783](https://github.com/tmustier/pi-for-excel/pull/783), [#796](https://github.com/tmustier/pi-for-excel/pull/796)
- Rules save without overwriting, imports with the same name are kept apart, and settings flows that were broken now work. JSON exports count only visible messages, the helper setup command is the same everywhere, and screen readers no longer hear a stale approval after Stop. [#788](https://github.com/tmustier/pi-for-excel/pull/788), [#790](https://github.com/tmustier/pi-for-excel/pull/790), [#806](https://github.com/tmustier/pi-for-excel/pull/806)
- Extension catalogues and credentials stay consistent, confirmation dialogs are exposed to accessibility tools, and the composer resizes once per edit in long chats. [#768](https://github.com/tmustier/pi-for-excel/pull/768), [#777](https://github.com/tmustier/pi-for-excel/pull/777)

## Updating

The hosted add-in updates automatically when you reopen its taskpane. The Excel manifest is unchanged, so existing installations do not need to sideload it again.

- **Stored data upgrade is one-way.** The first time the new version opens, it moves backups into the new storage. Older versions cannot open the upgraded storage.
- Each existing session misses the prompt cache once after updating, because the system prompt and tool descriptions changed.

Companion packages released with this version:

```bash
npx pi-for-excel-proxy@0.2.7-pre          # GitHub Copilot hosts
npx pi-for-excel-python-bridge@0.1.2-pre  # real Python errors, --install-missing
npx pi-for-excel-tmux-bridge@0.1.2-pre    # correct dev origin, --install-missing
```

## Verification and limits

Release preparation ran the full local gate on the release tree. See the [release preflight report](../release-smoke-runs/2026-10-27-release-preflight.md). Each constituent PR records real Excel acceptance on the web or on the Mac, driven by a real model, with independent workbook reads.

Shortcuts were checked on Windows 11 in Edge with real key events, including Polish and German AltGr layouts, but not inside Excel on Windows. Excel for Mac shortcuts were checked with the taskpane focused, using keys sent to Excel in the background. Windows Excel desktop, WPS and the full clean-install matrix were not rerun.
