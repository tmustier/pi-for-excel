# v0.11.0-pre release notes

Pre-release. Changes since [v0.10.0-pre](https://github.com/tmustier/pi-for-excel/releases/tag/v0.10.0-pre).

## Models and provider connections

- Upgrade Pi AI and Agent Core together from 0.80.6 to 1.3.0. GPT-6.1 Sol is now the default for OpenAI API and ChatGPT-backed connections, and Claude Opus 5.5 is the Anthropic default. Saved compaction summaries retain their existing format. [#765](https://github.com/tmustier/pi-for-excel/pull/765)
- Add a browser-native model runtime with persisted dynamic catalogs, background discovery for OpenAI-compatible gateways, and cached models for offline startup. Extensions can register providers through `api.models.registerProvider()`, with connection-scoped endpoints and cleanup on unload. [#653](https://github.com/tmustier/pi-for-excel/pull/653)
- Keep manual gateways on their configured model without discovery, and use matching registry metadata when saving. Existing context overrides remain until edited. Native OpenRouter Anthropic requests now use the configured proxy. [#708](https://github.com/tmustier/pi-for-excel/pull/708)
- Fix per-provider authentication fallback, duplicate startup refreshes, and the welcome overlay remaining open after credentials arrive. Keep the thinking popover inside short taskpanes. [#707](https://github.com/tmustier/pi-for-excel/pull/707), [#765](https://github.com/tmustier/pi-for-excel/pull/765)

## Images and MCP tools

- Apply model-specific image limits to prompt attachments and tool-result images using a background worker. Resizing and conversion preserve normalized history across model switches and cache replays. Limits also work with custom gateways and extension providers. [#736](https://github.com/tmustier/pi-for-excel/pull/736)
- Fix MCP Streamable HTTP connections that return JSON or SSE, including batches and streams that remain open after answering. Sessions and discovery caches are isolated by chat and connection configuration, concurrent initialization is shared, and cancellation no longer disrupts other callers. Expired sessions are invalidated without automatically replaying tool calls. Connection probes now report RPC and discovery failures. [#766](https://github.com/tmustier/pi-for-excel/pull/766)
- Cancel upstream proxy requests when the client disconnects, rather than leaving generation running. [#713](https://github.com/tmustier/pi-for-excel/pull/713)

## Workbook recovery and stored data

- Create recovery checkpoints for never-saved Excel workbooks using a document-scoped identity. Tighten WPS host detection. [#716](https://github.com/tmustier/pi-for-excel/pull/716)
- Recognize Save As immediately through live workbook file properties, without requiring a reopen. Clear temporary checkpoints at the first-save boundary and associate subsequent sessions and checkpoints with the saved file. [#717](https://github.com/tmustier/pi-for-excel/pull/717)
- Validate persisted recovery snapshots, file records, settings and tool-result metadata at their boundaries. Refactor workbook tools and session handling behind behavior tests. [#718](https://github.com/tmustier/pi-for-excel/pull/718), [#720](https://github.com/tmustier/pi-for-excel/pull/720), [#721](https://github.com/tmustier/pi-for-excel/pull/721), [#722](https://github.com/tmustier/pi-for-excel/pull/722), [#723](https://github.com/tmustier/pi-for-excel/pull/723), [#729](https://github.com/tmustier/pi-for-excel/pull/729)

## Updating

The hosted add-in updates automatically when you reopen its taskpane after deployment. The Excel manifest is unchanged, so existing installations do not need to sideload it again.

The companion proxy is released separately as `pi-for-excel-proxy@0.2.6-pre`. Restart an older proxy with:

```bash
npx pi-for-excel-proxy@0.2.6-pre
```

The proxy update includes OpenRouter target support and upstream request cancellation. No new tmux or Python bridge package is needed. The add-in itself is hosted on Vercel, not distributed as an npm package.

## Verification and limits

Release preparation passed checks, build and manifest validation, with 843 unit tests, 38 model tests, 623 context tests, 87 security tests, 3 manifest tests and 88 browser tests passing. The independently installed proxy tarball passed its audit and CLI smoke. See the [release preflight report](../release-smoke-runs/2026-10-17-release-preflight.md).

Real Excel for Mac acceptance is recorded in the constituent PRs:

- [#765](https://github.com/tmustier/pi-for-excel/pull/765): GPT-6.1 Sol/high called workbook tools, wrote and read back a formula, compacted the session, and switched to Claude Opus 5.5. Independent workbook and IndexedDB reads verified the results and cleanup.
- [#766](https://github.com/tmustier/pi-for-excel/pull/766): on the current release base with Pi 1.3.0, GPT-6.1 Sol/high called actual MCP and workbook tools in two chats. Independent HTTP logs, workbook reads and persisted tool results verified session isolation, reuse, formulas and stream cancellation.
- [#736](https://github.com/tmustier/pi-for-excel/pull/736): a model-created chart image passed through the actual Excel image worker path and persisted correctly. Oversized-image conversion was covered in Chromium, not real Excel.
- [#717](https://github.com/tmustier/pi-for-excel/pull/717): model-driven writes and independent identity checks verified the unsaved-to-saved transition, pane reload and workbook reopen.

The release changes version metadata and documentation only; it introduces no further runtime behavior. Windows Excel, WPS and the full clean-install matrix were not rerun for this pre-release. The focused Mac runs do not constitute full cross-platform certification. Pi Durable is a separate proposal and is not part of this release.
